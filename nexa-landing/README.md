# NEXA GROUP — лендинг

Одностраничный сайт по ТЗ «NEXA GROUP Master Technical Brief 2026» (разделы 11–14).
Чистый HTML/CSS/JS: сборка не нужна, открывается с любого статического хостинга.

## Файлы
- `index.html` — разметка, SEO-мета, Open Graph, Schema.org
- `styles.css` — дизайн-система (палитра из ТЗ, шрифты Unbounded / Inter / JetBrains Mono), адаптив 1440 / 980 / 640
- `script.js` — каталог 8 направлений с фильтром, экспресс-диагностика (5 вопросов → рекомендация пакета), формы → WhatsApp, UTM, события dataLayer
- `privacy.html` — политика конфиденциальности (нужна проверка юристом)
- `robots.txt`, `sitemap.xml`, `favicon.svg`, `vercel.json` (заголовки безопасности и кеш)

## Блоки главной (по разделу 12 ТЗ)
Hero → Боли → 8 направлений → Как работаем (BOS) + схема → Решения по задачам →
Продукты NEXA AI → Диагностика → Пакеты → Команда → FAQ → Заявка → Футер.

## Заявки
Все формы и диагностика открывают WhatsApp +7 707 779 96 56 с готовым текстом
(имя, телефон, ответы, UTM). Защита: honeypot, валидация, ограничение повторной отправки.

## Локальный просмотр
    python3 -m http.server 8000   # затем http://localhost:8000

## Перед запуском заменить
- Домен `nexagroup.kz` в `index.html`, `robots.txt`, `sitemap.xml` — на ваш
- `og.png` (картинка 1200×630 для соцсетей) — положить в папку
- ID Google Analytics 4 / GTM — вставить в `<head>`
- Реквизиты юрлица в `privacy.html`
