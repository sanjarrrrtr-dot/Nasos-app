# Школьный журнал — мини‑приложение

Простое веб‑приложение для школы: список учеников по классам, журнал оценок по предметам и отметки посещаемости.

## Возможности

- **Ученики** — добавление и удаление учеников, группировка по классам (5А … 11А).
- **Оценки** — выставление оценок (2–5) по предмету с датой, таблица «ученик × предмет» со средними баллами и итогом. Клик по оценке удаляет её.
- **Посещаемость** — отметки «Был / Опоздал / Не был» по дням, сводка за день. Повторный клик снимает отметку.

Данные хранятся в `localStorage` браузера, сервер не нужен.

## Запуск

Сборка не требуется. Откройте `index.html` в браузере — или запустите любой статический сервер из этой папки:

```bash
cd school-app
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Ограничения

- Данные привязаны к браузеру и устройству; очистка данных сайта их удалит.
- Нет входа и ролей (учитель/ученик/родитель) — это следующий шаг, если понадобится.
- Для работы с несколькими учителями нужен бэкенд и база данных.

## Запуск в Telegram (Mini App)

Приложение открывается внутри Telegram как Mini App. Для этого нужен публичный HTTPS‑адрес.

1. **Хостинг.** Workflow `.github/workflows/school-app-pages.yml` публикует папку `school-app/` на GitHub Pages.
   В настройках репозитория: *Settings → Pages → Source: GitHub Actions*. После деплоя адрес будет вида `https://<owner>.github.io/<repo>/`.
2. **Бот.** В @BotFather выполните `/newbot`, затем `/newapp` (или `/mybots → Bot Settings → Menu Button → Configure menu button`) и укажите HTTPS‑адрес из п. 1.
3. Откройте бота в Telegram и нажмите кнопку меню — откроется журнал.

Что делает интеграция: подключает `telegram-web-app.js`, разворачивает приложение на весь экран и берёт цвета из темы Telegram.

**Важно:** данные по‑прежнему хранятся в `localStorage` на каждом устройстве. Общий журнал для учителей и синхронизация между телефонами потребуют бэкенд (например, Supabase).

## Настройка под школу

Все параметры брендинга лежат в `school-app/config.js`:
- `name`, `subtitle`, `shortMark` — название, подзаголовок и буква в значке;
- `accent`, `accent2` — цвета;
- `classes` — список классов школы;
- `demo` — вымышленные ученики для показа. Уберите блок, чтобы начать с пустого журнала.

Не используйте логотип и название школы без её разрешения. Демо‑данные должны оставаться вымышленными, без реальных учеников.
