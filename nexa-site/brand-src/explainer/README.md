# Видео «NEXA GROUP за минуту»

58 секунд, голос, музыка, субтитры. Две версии:
- `public/media/nexa-explainer.mp4` — 1280×720, для сайта и YouTube;
- `public/media/nexa-explainer-vertical.mp4` — 1080×1920, для Reels и Stories.

## Как собрано
1. **Текст** — `script.json`: `text` идёт в субтитры, `say` читает голос (аббревиатуры написаны
   так, как их нужно произносить; «вАтсап» задан фонетикой `[[ vvˈɑtsʌp, ]]`, чтобы ударение было верным).
2. **Голос** — Piper TTS, голос `ru_RU-dmitri-medium` (rhasspy/piper-voices на Hugging Face),
   скорость `length_scale=1.07`. Ударения проверены по фонетической записи espeak.
3. **Музыка** — `make_music.py`, сгенерирована с нуля (пэд + арпеджио), без чужих треков.
4. **Расписание** — `schedule.json`: начало каждой фразы; пауза между сценами 1,2 с.
5. **Картинка** — `film.html`, функция `render(t)`; `render_film.js` снимает кадры через Playwright
   (`h` — горизонтально, `v` — вертикально), ffmpeg собирает кадры и звук в mp4.

Чтобы заменить голос (свой или ElevenLabs): запишите фразы, обновите длительности в `schedule.json`,
пересоберите звук и видео. Анимация подстроится под новые тайминги.
