# Telegram‑бот «Кабинет школы» (демо)

Бот с кнопками для родителя: выбор ученика, расписание, замены, оценки и сообщения класса. Данные вымышленные. Текст диалога — в `script.md`.

## Файлы

- `bot.js` — логика бота и запуск через long polling. Без внешних зависимостей, нужен Node.js 18+.
- `test.mjs` — проверки диалога без обращения к Telegram.
- `script.md` — текст диалога по шагам.

## Проверка

```bash
cd school-bot
node test.mjs
```

## Создание бота

1. В Telegram откройте @BotFather, отправьте `/newbot` и задайте имя и username.
2. Скопируйте токен. Его нельзя класть в репозиторий.
3. Чтобы кнопка «Открыть кабинет» открывала Mini App, опубликуйте `school-app/` (GitHub Pages) и укажите адрес в `MINI_APP_URL`. Без этого кнопки нет, остальной бот работает.

## Запуск

```bash
export TELEGRAM_BOT_TOKEN='123456:ABC...'
export MINI_APP_URL='https://<owner>.github.io/<repo>/'   # необязательно
node bot.js
```

Бот работает, пока запущен процесс. Для постоянной работы разверните его на сервере или хостинге, который держит процесс (например, VPS или Render с платным планом). Бесплатные «спящие» хостинги не подходят для long polling.

## Ограничения демо

- Данные лежат в `makeDemo()` в `bot.js`, это не реальная школа.
- Выбор ученика хранится в памяти процесса и сбрасывается при перезапуске.
- Бот не изменяет данные: только показывает.
- Для реальной школы нужен источник данных (база или API школы) и доступ администратора. Без этого бот — прототип для показа.
